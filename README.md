# Carpet Study Program (Парсер каталога Amikovry)

Веб-утилита для автоматического парсинга каталога ковров с сайта amikovry.ru, сохранения данных в реляционную базу данных PostgreSQL и последующего экспорта актуальной информации в формат Excel (.xlsx).

---

## Технологический стек

* **Backend:** Java 21, Spring Boot 3, Spring Data JPA, Hibernate, Jsoup
* **База данных:** PostgreSQL
* **Работа с файлами:** Apache POI (генерация Excel)
* **Инфраструктура:** Docker, Docker Compose

---
## Структура базы данных

* **Схема:** `carpet_study_program_schema`
* **Таблица:** `carpets`
* При каждом запуске парсинга данные в базе атомарно обновляются (старые записи заменяются свежими актуальными данными с сайта).

---

## Настройка окружения (.env)

Перед первым запуском проекта создайте в корневой папке файл с именем `.env` и пропишите в нем доступы для базы данных:

```env
DB_USERNAME=ваш_логин
DB_PASSWORD=ваш_пароль
```

## Основные возможности
* Автоматический сбор параметров ковров (бренд, коллекция, страна, материал, состав ворса/основы, 
* тип производства, плотность, размеры, особенности и вес).
* Мгновенная выгрузка всей базы в структурированный Excel-файл с текущей датой в названии.
